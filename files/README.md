# `files/` 自定义覆写目录说明

放置在此目录下的文件（除本 `README.md` 外），会在编译阶段按**原相对路径**复制到上游源码的 `openwrt/files/` 目录，并直接打包进固件只读根文件系统（ROM）。

## 当前已预置文件

- `etc/uci-defaults/99-wh3000pro-custom`
  - 固件首次（无旧配置）启动时执行一次。
  - 自动探测 `pwmfan` 当前对应的真实 `hwmon` 节点（兼容 `hwmon1` / `hwmon2` 因 PHY 传感器顺序变化产生的编号漂移），并将准确路径与温控参数写入 `/etc/config/fancontrol`。

## 后续扩展放置示例

若后续需要将路由器上自用的非私密适配脚本（例如 T99W368 定制守护或工具脚本）一并编入固件，可按对应系统路径放置：

```text
files/
├── etc/
│   ├── init.d/            # 自定义开机服务脚本（编译脚本会自动赋予 +x 权限）
│   └── uci-defaults/      # 首次开机初始化脚本
└── usr/
    ├── lib/lua/           # 自定义 Lua 库
    └── share/qmodem/      # 自定义 QModem 扩展脚本
```

> **重要提醒（公开仓库安全红线）**
>
> 本仓库为公开仓库，**严禁**将以下内容放入 `files/`：
> - WiFi 密码、路由器 root 密码哈希（`/etc/shadow`）、SSH 私钥
> - 代理订阅链接、节点配置、VPN 密钥
> - 含个人敏感信息的 APN / 账号 / 手机号配置
